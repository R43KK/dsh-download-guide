# DeepSeek Harness 下载与安装资源站

[deepseekzy.com](https://deepseekzy.com/) — 一个专注于 DeepSeek Harness（命令行 `dsh`）的第三方资源整理站。

**非官方声明**：本站与 DeepSeek 官方无隶属关系，只整理官方下载入口、SHA256 校验方法与安装排障，不提供破解或修改版安装包。

## 这里整理了什么

DeepSeek Harness（`dsh`）目前有三种形态：**Windows / macOS 桌面客户端**、**命令行工具（npm 或源码安装）**、**本地 Web 界面（`dsh web`）**。本站把三类形态的官方下载入口、校验方法、安装步骤与常见报错集中到一处，方便快速定位需要的包和配置。

| 内容 | 说明 |
| :--- | :--- |
| Windows 安装版 / 便携版 | `.exe` 入口与 SHA256 校验值 |
| macOS 双架构 dmg | arm64 与 x64，含芯片识别指引 |
| CLI / npm 安装 | `npm i -g @deepseek-ai/dsh` 及源码构建路径 |
| 本地 Web 界面 | `dsh web` 启动方式与配置说明 |
| 安装教程 / 排障 | 从零跑通 + 卡住时的排查方向 |
| 离线包与镜像 | 官方原始地址 + 校验值 + 国内可用镜像 |

> 下载后建议先计算 SHA256 并与页面给出的校验值比对，再执行安装。搜索结果中仿站较多，域名与哈希两项都通过，再继续操作。
